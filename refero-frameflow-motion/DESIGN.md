# Frameflow — Lottielab Motion Study

## Reference
- Refero style: https://styles.refero.design/style/1f782141-d407-4c27-8cee-2246720a9f42
- Reference product: Lottielab
- Study goal: extract the bright-paper animation-studio grammar and explore what kind of motion feels native to it rather than simply animating everything.

## Visual DNA
- Near-white / Pebble canvas with Paper surfaces.
- Mist hairline borders instead of shadows.
- Deep Indigo text rather than pure black.
- Electric Violet is the single dominant chromatic fill.
- Geometric sans typography with tight large-heading tracking.
- Comfortable 8px spacing rhythm and quiet 8px card radius / 12px button radius.
- Product UI is the hero visual, not decorative illustration.

## Motion Thesis
The reference already looks like an animation tool, so motion should feel **editorial and explanatory rather than cinematic**.

The demo therefore synchronizes three layers:
1. the object moving in the preview,
2. the timeline playhead,
3. the keyframes becoming active.

The interface itself stays visually calm while the authored content moves.

## Main Demo
A fictional animation editor named **Frameflow**.

### Preview animation
- One Electric Violet object travels across the artboard.
- Position, rotation, scale and corner radius change together.
- A thin violet ring follows as a secondary motion cue.
- Headline copy fades and rises in during the latter half of the loop.

### Timeline
- 4-second loop.
- Tracks for Shape / Ring / Headline / Opacity.
- Playhead advances in sync with the preview.
- Keyframe diamonds fill violet as the playhead crosses them.
- User can play, pause, restart and scrub.

## Motion Cards
Three smaller looping studies explain the motion language:
- Position: a violet rounded square travels and morphs.
- Shape: an outlined circle squashes and stretches.
- Timing: one violet word becomes the visual beat.

## Core Principles
- **The editor stays still; the authored object moves.**
- **Motion must explain state or relationship.**
- **One chromatic actor per viewport.** Violet carries the moving focus.
- **Timeline and preview should tell the same story.** Motion UI feels believable when playback state is synchronized.
- **No shadows needed.** Borders and neutral surface stepping preserve the reference grammar.

## Responsive Rule
Desktop keeps Layers / Stage / Timeline visible together. Mobile compresses Layers but preserves the animation preview and interactive timeline rather than hiding the editor UI.

## Source Notes
Refero describes the reference as an “animation studio on bright paper,” with #7270ff as the primary chromatic fill, near-white neutral surfaces, 1px Mist borders, oversized tight-tracked headings, and product/editor UI as the main visual weight. Those constraints are treated as the source grammar rather than copied branding or content.
