02 / GLASS DOCK

A selection can move without redrawing the whole interface.

The glass shell stays fixed. Only the inner selection material slides between destinations, keeping the dock calm while still feeling tactile.

03 / CONTROL CENTER

Dense controls need local glass, not global glass.

Each control remains readable because the blur is concentrated inside one panel. Toggle the tiles and adjust brightness or volume without changing the page underneath.
