# Orbit — Retrospective

## What worked
- The reference is unusually reproducible from DESIGN.md because its identity is expressed as a small number of strict rules: pure black, huge regular-weight type, sparse layout, one violet CTA and one procedural visual signature.
- Avoiding cards entirely makes the page feel substantially less like generic AI/SaaS output.
- Procedural DOM particles are enough to establish the constellation language without external image assets.
- Replacing the original workplace-search concept with collective memory still feels native because the visual metaphor — distributed points becoming knowledge — survives the conceptual translation.

## Risks / Improvements
- Random particles currently form an abstract organic cloud, not a precise recognizable brain. A deterministic SVG/Canvas field could improve art direction and consistency.
- Too much particle animation would quickly turn the page into a WebGL demo and weaken the editorial calm.
- Inter cannot perfectly reproduce PPNeueMontreal geometry, so spacing and line breaks should be treated as approximations.

## Reusable Knowledge
- When a reference has a strong DESIGN.md, reproduce **role constraints** before component appearance.
- Dark design does not imply dark surfaces: sometimes the absence of surfaces is the defining rule.
- A single procedural motif can replace a large image asset library if the motif is distinctive enough.
- For oversized typography, preserve the large mobile scale; shrinking it to conventional mobile headings removes much of the identity.
