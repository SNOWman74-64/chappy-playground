# Design

## Reference
[共通設計](../experiments/social-game/DESIGN.md)、[受入れ基準](../experiments/social-game/ACCEPTANCE.md)、[計測手順](../experiments/social-game/PROTOCOL.md)に従う。他試行は参照しない。

## Intent
「今やること→調べる→相談する」を短い導線でつなぐ。共通の固定データ全件を使う。

## Visual DNA
濃紺の細いナビゲーション、明るい紙面、青緑の操作、金色の章番号。トップは小さな導入とイベント画像、更新情報、初心者導線を並べる。本文を画像に重ねず、図鑑では肖像を情報の目印にする。

## Tokens
背景 #f4f6f8、紙面 #fff、本文 #172638、補助 #536477、濃紺 #12243a、操作 #087e8b。本文16px、行間1.75。角丸6px、重い影なし。最大幅1200px、余白24px、操作44px以上。

## Layout Anatomy
デスクトップは主本文と280pxの案内欄。図鑑は4列、モバイル2列。820px以下は単列本文。640px以下は開閉ナビ。記事は読み幅を抑える。フォームは明示的ラベル、確認段階、エラー欄を持つ。

## Interaction / Motion
ハッシュURLで詳細・検索・図鑑フィルター・編成を復元。主要遷移後は見出しにフォーカス。保存差分は専用キーに格納し、失敗時は一時利用を明示。確認ダイアログは標準dialogでEscape・取消に対応。動きは必須にしない。

## Constraints
単騎・委託なし。依存追加なし。共通入力は読取り専用。commit/push/公開/共有カタログ編集なし。実時間でイベント状態を変えない。予算・制限時間は指定なし、受入れ項目を証拠で確認するまで実施。独立評価はこの担当では行わない。

## Adaptation from reference
特定サイトの複製ではない。4枠を常に明示する編成、区切り線中心の記事一覧、本文中心の掲示板を採用する。

初回保存後は、モバイルのガイド導線を上部に追加し、イベント画像の全体表示と見出しの行長調整を行った。ユーザー入力の長い連続文字はパンくず・本文・一覧で折り返す。差分と再検証はTEST-REPORT.mdに記録。
