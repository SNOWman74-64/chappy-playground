# Site Knowledge Index

特定の UI site / product / gallery を深掘りした時の design DNA を保存する場所。

サイトごとの知識は、その Reference の再現や応用には使えるが、UI Lab 全体の恒常ルールではない。

| Site ID | Site | Status | Tags | Profile |
| --- | --- | --- | --- | --- |
| SITE-THREEUI | ThreeUI | seed | threejs, shader, hero, webgl, interaction, mobile-adaptation | `threeui/INDEX.md` |

## Profile lifecycle

```text
reference candidate
→ seed profile
→ reproduction evidence
→ confirmed site-specific grammar
→ repeated across other sources/studies
→ LEARNINGS candidate
```

新しいサイトを追加する時は、最初に `sites/<slug>/INDEX.md` だけ作り、深掘りが必要になったカテゴリだけ別ファイルへ分ける。
