# Current Design Preference Hypotheses

実例と study を通して検証中の好み。**恒常ルールではない。**

AI は新規探索の初期バイアスとして使ってよいが、`DESIGN.md` や要件と衝突する場合はそちらを優先する。

| ID | Hypothesis | Status |
| --- | --- | --- |
| PREF-001 | 全要素を均等な Card に入れるより、Typography / whitespace / divider で階層を作る表現を好む傾向がある | candidate |
| PREF-002 | 画面の Primary が明確な構成を好む | candidate |
| PREF-003 | 情報量が多くても視線が迷わない UI を好む | candidate |
| PREF-004 | Motion は状態・素材・操作を伝える時に特に好む | candidate |
| PREF-005 | Web site では Layout / Typography / whitespace に大胆さがある方向を好む | candidate |
| PREF-006 | Web app では操作効率と state clarity を強く重視する | candidate |
| PREF-007 | Mobile は desktop の縮小より、用途に合わせた再構成を好む | candidate |
| PREF-008 | 理由のない Card / Pill / Gradient / Decoration を避ける傾向がある | candidate |
| PREF-009 | Blender / Three.js / 2.5D / Paper Diorama は通常 Web Design と分けた特殊表現レーンとして研究する | active research direction |

同じ変更や判断が複数の Reference / study で繰り返され、直接 evidence が残った場合のみ `LEARNINGS.md` への昇格候補にする。
