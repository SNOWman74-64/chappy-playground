# Design

## Reference

実在校の模倣は行わず、共有設計計画 [../school-comparison/DESIGN-PLAN.md](../school-comparison/DESIGN-PLAN.md) と共有設計ルール [../DESIGN.md](../DESIGN.md) を参照した。学校名、人物、住所、実績、日程はすべて架空である。

## Intent

variant B は、写真で学校の空気を伝えながら、受験生が「学校を知る → 学び・生活を知る → 説明会を選ぶ → 入力・確認・完了」へ迷わず進める編集型の学校サイトとして実装する。在校生・卒業生向けの導線もフッターと補助ナビに置く。

## Visual DNA

白地と生成りの面を基調に、深い緑を信頼感、若葉色を学びの余白、金色を現在地や小さなアクセントとして使う。大きな明朝見出しと本文のゴシックを組み合わせ、写真と細い罫線で学校案内の冊子らしいリズムをつくる。情報をすべてカードに閉じず、罫線・余白・背景面で階層を示す。

## Tokens

- 深緑 `#163f35` / 深い背景 `#0e2d26`
- 若葉 `#dce8c9` / 生成り `#f6f5ef`
- 本文 `#243a32` / 補助 `#58675e` / 金 `#b9904d`
- 本文16px以上、注記14px目安、主要ボタン48px以上
- 最大本文幅1200px、8pxを基準に余白を設計
- 明確な `:focus-visible`、十分なコントラスト、画像欠落時の色面フォールバック

## Layout Anatomy

`index.html` のハッシュルーティングで、トップ、学校紹介、学び、学校生活・施設、部活動、入試・説明会、お知らせ、アクセス・FAQ、お問い合わせ・資料請求、検索、印刷用学校案内、在校生・卒業生・プライバシー・サイトマップを独立URL相当のルートとして提供する。ヘッダーは主要ナビ・サイト内検索・資料請求、フッターは補助案内・写真クレジットを持つ。

variant B の固有判断は、トップで「学校の約束 → 重要案内 → 4つの入口 → 最新情報 → 説明会」の順に置き、学校案内を読む視線の流れを作ったこと。詳細ページではカードの連続を避け、タイムライン、表、罫線リスト、写真グリッドを使い分けた。

## Interaction / Motion

- ハッシュルートでブラウザの戻る・進む・直接表示に対応
- ヘッダー検索はタイトルと本文のローカル検索。検索結果、件数、0件状態を表示
- お知らせと部活動は分類フィルターでその場の一覧を更新し、詳細ページへ遷移可能
- 説明会予約とお問い合わせは、必須項目・メール形式・同意をブラウザ検証し、入力 → 確認 → 修正／完了のデモフローを持つ。外部送信・永続保存はしない
- モバイルメニューは開閉、遷移後の閉鎖、Escape に対応
- FAQ はネイティブ `details`、主要な操作はキーボードと focus-visible で操作可能
- 写真は `../school-comparison/assets/` の `campus.jpg`、`library.jpg`、`classroom.jpg`、`basketball.jpg` を参照し、未配置時は背景色に退避する

## Constraints

依存パッケージなしの静的 HTML / CSS / JavaScript とし、共有ファイル、カタログ、他案の実装は変更しない。外部業務システムや認証、実在の連絡先への送信を模倣しない。フッターの写真クレジットは親側の `../school-comparison/ASSETS.md` にリンクする。

## Adaptation from reference

参照サイトのコピーではなく、共有計画で定められた情報要件とビジュアル DNA を、写真中心の編集レイアウトと明確な予約導線に翻訳した。variant B では、トップの入口タイル、説明会の日程カード、紙面を想起させる罫線と余白、印刷用学校案内を重視した。
