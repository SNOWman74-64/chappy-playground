# Design

## Reference
[共通設計](../experiments/social-game/DESIGN.md)、[受入れ基準](../experiments/social-game/ACCEPTANCE.md)。他試行の実装や評価は参照しない。

## Intent
今やるイベント、キャラの使い方、攻略と相談にすぐ到達する。Astraが設計判断と全確認、Lunaが実装・修正を担当する。ユーザーの追加指示により実装担当のブラウザ接続条件をAstraによる検証へ変更。

## Visual DNA
小さな星環の記号と濃紺のナビで世界観を示し、攻略本文は明るい紙面。トップは短いタイトル帯に続き、開催イベントの画像と説明を別領域で配置。大型ヒーローは使わない。情報密度は行と区切り線で整え、全項目のカード化を避ける。

## Tokens
背景 #f4f6f8、紙面 #ffffff、本文 #172638、補助 #536477、濃紺 #12243a、操作 #087e8b、金 #b57d20。本文16px、補助14px。見出し28〜36px。最大幅1200px、デスクトップ余白32px、モバイル16px。主要操作44px以上。角丸4〜8px、影は最小限。

## Layout Anatomy
ヘッダー：ロゴ、主要ナビ、検索。トップ：更新日と短い案内、開催イベントと初心者導線、更新記事、キャラ入口、掲示板の最近の相談。PCは主列と補助列、390pxは1列。図鑑はPC4〜6列・モバイル2列。記事と投稿の本文幅は約720px。キャラ詳細は左画像と右能力概要、下にスキル・素材・相性。パンくずと戻り先を用意する。

## Interaction / Motion
ハッシュURLと履歴、フォームは明示ラベル。投稿は入力・確認・修正・完了、編集削除は所有者のみ。モバイルメニューはEscapeと遷移で閉じる。フォーカスは青緑の外枠。共通データは変更せず、localStorage差分を専用名前空間で管理。破損・拒否時の説明と復旧導線を持つ。

## Constraints
HTML/CSS/JSのみ、依存追加なし。共有入力・カタログを変更しない。commit/push/公開なし。確認はAstraが担当し、Lunaは確認済みと自己申告しない。未検証は明記する。

## Adaptation from reference
共通設計の数値と全機能を維持する。代表下層はキャラ詳細c01。レビューは第一画面＋代表下層、完成時の2回。修正後の再検査は確認であり新しい設計レビューとは区別。制作の目安予算は90分、超過は記録する。初回提出物はレビュー前に別アーカイブへ保存する。
