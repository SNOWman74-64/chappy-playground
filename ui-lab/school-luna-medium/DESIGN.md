# Design

## Reference

[共有設計計画](../school-comparison/DESIGN-PLAN.md) と [UI Lab共有設計](../DESIGN.md)。特定の実在校は模倣せず、指定された共通写真を使用する。

## Intent

受験生と保護者が「学校を知る → 学び・生活を知る → 説明会を選ぶ → 予約する」まで迷わず進める、写真主役の学校サイトにする。

## Visual DNA

深い緑、生成り、若葉色、細い罫線、大きな明朝見出しと読みやすいゴシック本文。カードは入口や比較情報に限定し、ページ全体は余白と水平線で編集的に構成する。

## Tokens

共有トークンを採用：`#163f35`（深緑）、`#dce8c9`（若葉）、`#f6f5ef`（生成り）、`#243a32`（本文）、`#58675e`（補助）。本文16px基準、最大幅1200px、8px単位の余白、44px以上の主要操作。

## Layout Anatomy

Sticky headerに主要ナビと検索を置く。トップは写真ヒーロー、重要案内、3つの入口、説明会、ニュースの順。下層はページタイトル帯 → セクション → 罫線/最小限のカード。フッターには在校生・卒業生・プライバシー・サイトマップ・素材クレジットを置く。

## Interaction / Motion

ハッシュルーティングで直接表示・戻る/進むに対応。検索はタイトル・本文のローカル検索。ニュースと部活動は分類フィルター。説明会予約は必須/メール形式/同意をブラウザ標準検証し、確認・修正・デモ完了まで進める。資料案内は印刷ダイアログを開く。モバイルメニューはEscapeと遷移で閉じる。装飾モーションは使わず、状態変化を明示する。

## Constraints

静的HTML/CSS/JSのみ。外部送信・永続保存・認証・実在連絡先は使わない。写真は `../school-comparison/assets/` の共通素材のみ。別バリアントやカタログ、共有ファイルは変更しない。

## Adaptation from reference

参照の再現ではなく、共通設計の情報構造からD案として、生成りの余白・深緑の編集的な水平線・写真と実務情報の交互配置を強めた。情報量の多い入試/FAQを検索とハッシュ遷移で見つけやすくした。
