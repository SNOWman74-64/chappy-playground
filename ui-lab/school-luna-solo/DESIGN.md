# Design

## Reference

共通設計計画は [../school-comparison/DESIGN-PLAN.md](../school-comparison/DESIGN-PLAN.md) を採用した。計画に記載された5枚の共通写真を相対URLで利用し、出典は [../school-comparison/ASSETS.md](../school-comparison/ASSETS.md) に準拠している。特定の実在校の模倣ではなく、架空の「私立 青葉高等学校」公式サイトデモとして制作した。

## Intent

受験生と保護者が、学校の空気を写真で感じながら、学校紹介・学び・生活から説明会予約まで迷わず進めることを目的にした。ニュースと部活動は探しやすさを優先し、ハッシュルーティングで直接表示・戻る／進むに対応する。

## Visual DNA

- 白地・生成り・深緑を軸に、細い罫線と大きな明朝見出しで落ち着いた学校案内の印象をつくる。
- 写真はヒーロー、導線、施設紹介で主役にする。カードの角丸や強い影は使わず、余白・罫線・背景差で情報の役割を分ける。
- 本文は読みやすいゴシック、見出しは明朝。アクセントの茶色は日付・番号・小見出しに限定する。
- 画面幅に応じて1列化し、モバイルでは固定のモバイルナビに切り替える。

## Tokens

共通計画のトークンを採用した。深緑 `#163f35`、若葉 `#dce8c9`、生成り `#f6f5ef`、本文 `#243a32`、補助 `#58675e`。本文16pxを基準、注記14px、主要操作は44px以上。`focus-visible` は茶色の3pxアウトラインで表示する。

## Layout Anatomy

`index.html` を正規入口とし、`app.js` のハッシュルーターでトップ、学校紹介、学び、学校生活・施設、部活動、入試・説明会、お知らせ、アクセス・FAQ、お問い合わせ・資料請求、在校生、卒業生、プライバシー、サイトマップを表示する。ニュース・部活動の詳細は `#news/id` と `#clubs/id`、検索は `#search?q=...`、予約は `#reserve?event=...` とした。

トップは写真ヒーロー、重要案内、教育方針、学校生活入口、最新ニュース、統計、説明会導線を順番に置いた。下層ページはページヒーロー、主要コンテンツ、補助案内の2カラムを基本とし、フォームだけは確認・完了の状態を同一ページで切り替える。`guide.html` は印刷用学校案内の独立ページで、ブラウザの印刷ダイアログを使う。

## Interaction / Motion

サイト内検索はタイトルと本文のローカル検索で、結果・0件状態を表示する。お知らせと部活動は分類フィルターを持つ。フォームは必須項目・メール形式・同意のバリデーション、入力→確認→編集→完了のデモを実装した。入力データはJavaScriptのメモリ内だけで、外部送信・永続保存をしない。モバイルメニューは開閉とEscapeに対応し、フォームやFAQの状態は意味のあるラベルと`aria-expanded`で表現する。装飾アニメーションは最小限にした。

## Constraints

- 現在ディレクトリ内の静的HTML/CSS/JavaScriptだけを変更した。
- 依存パッケージ、外部フォーム送信、個人情報の永続保存、Git、カタログ、共有設計ファイルは変更していない。
- 写真は `../school-comparison/assets/` の指定5枚だけを相対参照している。
- すべての学校名・人物・住所・電話番号・日程・進路データ・入試情報は架空である。
- [../DESIGN.md](../DESIGN.md) の共通ハーネス要件に合わせ、実装判断をこの文書に記録した。

## Adaptation from reference

共通計画のVisual DNAと必須ページ／フローは維持し、レイアウトは「編集部のような縦の読み順」と「写真→情報→申込みの段階的な導線」に寄せた。比較対象の他実装は参照せず、計画と共通素材だけを基準に独立実装した。
