# Design

## Reference

[共有設計計画](../school-comparison/DESIGN-PLAN.md) と [UI Lab 共通設計](../DESIGN.md) を参照した。実在校の模倣は行わず、架空の「私立 青葉高等学校」を独立実装している。

## Intent

学校の空気を写真で伝えながら、受験生・保護者が「学校を知る → 学びと生活を知る → 説明会を選ぶ → 予約する」まで迷わないことを優先した。在校生・卒業生には必要な情報へ短く到達できる補助導線を用意した。

## Visual DNA

深緑を基調に生成りの背景、細い罫線、大きな明朝見出し、ゴシック本文で構成した。variant E は「月明かりと余白」を解釈軸に、丸い月の校章モチーフと、情報を閉じ込めすぎない水平のルール・余白を採用した。写真はヒーローと施設紹介で主役にし、装飾的なアニメーションは使わない。

## Tokens

- 深緑 `#163f35`、若葉 `#dce8c9`、生成り `#f6f5ef`、本文 `#243a32`、補助 `#58675e`
- 補助アクセントは金色 `#b38b4c`。校章、日付、重要な視線誘導に限定する。
- 本文は16px基準、注記は12〜14px、主要ボタンは46px、本文最大幅1200px。

## Layout Anatomy

`index.html` を共通シェルとし、ハッシュルーティングで独立ページ相当の状態を提供する。トップは写真ヒーロー、重要案内、写真入口、3つの探索導線、ニュース、メッセージの順。下層はページヒーロー、短い導入、役割に応じたルール・表・写真・最小限のカードの順で構成した。施設は6件、部活動は運動部・文化部計8件、お知らせは8件、FAQは7件を収録している。

## Interaction / Motion

検索はタイトル・本文を対象にしたローカル検索で、結果と0件状態を表示する。お知らせ・部活動はボタンによる絞り込み、ニュースは詳細表示に対応する。説明会予約とお問い合わせ・資料請求は必須項目・メール形式・同意を検証し、入力→確認→完了のローカルデモを実装した。モバイルナビは開閉・Escape・遷移後の閉鎖に対応し、`focus-visible` と主要フォームラベルを整えた。モーションは画像の小さなホバー拡大と状態遷移に限定した。

## Constraints

静的HTML/CSS/JavaScriptのみ。新規依存、外部送信、永続保存、認証、実在校の情報は使用しない。共有写真は `../school-comparison/assets/` から参照し、写真クレジットはフッターから `../school-comparison/ASSETS.md` にリンクした。親担当がブラウザQAを行うため、この担当ではブラウザ操作を実施しない。

## Adaptation from reference

共有計画の情報要件とトークンを守りつつ、variant E では「月影」「問いの灯り」をコピーではなく独自の文体・構成に落とし込んだ。ページはハッシュルートにまとめ、ギャラリー側の共有ファイルや他バリアントは変更していない。
