# 比較ページの表示修正

2026-09-07。Variant Cの追加後、比較カードが下部のリンク・計測表に重なるという報告を受けて確認した。

現在のHTMLでは重なりは再現しなかったが、Cのみ代替画像で、本文量によってボタンの高さもずれていた。3案とも実サイトのスクリーンショットを使い、プレビューの高さを固定、本文を縦方向のflex配置にしてボタンを下端へ揃えた。追加済みのCへのリンクと計測値の「未取得」表示は維持した。

実ブラウザで1325px・820px・390pxを確認。各幅で本文がカード内に収まり、リンク群が全カードの下に配置され、ページ全体の横あふれ・画像欠落がないことを確認した。1325pxでは全プレビュー300px、3ボタンの上端は同一位置。390pxではプレビュー270pxで1列表示。横幅のある計測表は表の領域内で横スクロールする。
