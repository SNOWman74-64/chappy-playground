# Design

## Reference

[DESIGN-PLAN.md](./DESIGN-PLAN.md) を共通設計計画として使用する。実在校の模倣ではなく、架空の「私立 青葉高等学校」を題材にした比較用サイトである。

## Intent

受験生と保護者が、学校の雰囲気を写真から掴みつつ、学び・学校生活・部活動・入試・説明会へ迷わず移動できる構成にする。

## Visual DNA

白と生成りを基調に深緑をアクセントとして使う。大きな明朝見出し、読みやすいゴシック本文、細い罫線、広めの余白を中心にし、写真を主要な視覚要素として扱う。

## Tokens

深緑 `#163f35`、若葉 `#dce8c9`、生成り `#f6f5ef`、本文 `#243a32` を基準とする。本文16px以上、主要操作は44px以上、最大本文幅は1200pxを目安とする。

## Layout Anatomy

今回一覧へ追加する表示対象は `school-astra/`。トップから学校紹介、学び、学校生活・施設、部活動、入試・説明会、お知らせ、アクセス・FAQ、お問い合わせへハッシュルーティングで遷移する。

## Interaction / Motion

サイト内検索、ニュースと部活動の絞り込み、詳細表示、FAQ開閉、モバイルメニュー、説明会予約と問い合わせの入力・確認・完了フローを提供する。装飾目的の動きは抑える。

## Constraints

静的HTML/CSS/JavaScriptのみを使用する。外部送信や永続保存は行わず、学校名・住所・人物・日程・実績は架空とする。写真は `assets/` の共通素材を利用する。

## Adaptation from reference

比較実験で使った共通設計を維持しつつ、今回の実装は情報量の多い学校サイトを一つの静的アプリとして扱い、各機能へ短く移動できることを優先した。
