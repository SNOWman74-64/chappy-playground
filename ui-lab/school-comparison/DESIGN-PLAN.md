# 青葉高等学校：同じ設計から2つのサイトを制作する

2026年9月7日作成。対象は受験生と保護者。学校の日常を写真で伝え、学校理解から説明会の申込みまで迷わず進める公式サイトのデモを、同じ条件で独立して実装する。

## Reference
特定の実在校は模倣しない。学校名・人物・住所・実績・日程は架空。共通のストック写真（画像生成サービスの404エラーにより変更）を利用し、フッターに架空サイトであることを明記する。

## Intent
学校の空気が伝わる写真と、入試情報を探しやすい実務的な案内を両立する。主導線は「学校を知る → 学び・生活を知る → 説明会を選ぶ → 入力・確認・完了」。在校生には行事・お知らせ・各種案内への短い導線を用意する。

## Visual DNA
緑の多い日本の私立共学校。白地、深い緑、細い罫線、大きな明朝の見出し、読みやすいゴシック本文。写真を主役に、広い余白と整列で階層をつくる。情報をすべて角丸カードに閉じ込めない。装飾アニメーションは控える。2案のレイアウト判断は各実装者に委ねる。

## Tokens
深緑 #163f35、若葉 #dce8c9、生成り #f6f5ef、本文 #243a32、補助 #58675e。本文16px以上、注記14px目安。最大本文幅1200px。8px基準の余白。主要ボタン44px以上。明確なfocus-visibleと十分なコントラスト。

## Layout Anatomy
共通の校名は「私立 青葉高等学校 / AOBA HIGH SCHOOL」、標語は「好きが、未来をひらく。」。創立1968年、各学年6クラス、探究・総合・国際の3コースという架空設定。

| --- | --- |

独立URLを持つ複数ページ、またはハッシュルーティングを採用する。ブラウザの戻る・進む、ページ直接表示に対応。ヘッダーに主要ナビ、サイト内検索、資料請求。フッターに在校生・卒業生案内、プライバシー、サイトマップを置き、それぞれ内容のある遷移先を設ける。

## Interaction / Motion
検索はタイトル・本文のローカル検索で、結果と0件状態を表示。ニュース・部活を絞り込みできる。詳細を開いて戻れる。説明会予約は日程・氏名・メール・参加人数・同意を検証し、確認後にデモ完了を表示。外部送信は行わず、個人情報は永続保存しない。資料は実際に開ける印刷用学校案内を提供。モバイルメニューは開閉・遷移後の閉鎖・Escapeに対応。キーボード操作、フォーカス、読み上げラベルを整える。

## Constraints
既存UI Labの静的HTML/CSS/JavaScript方式を使う。新規依存導入、Git操作、外部公開、実在の連絡先への送信は行わない。架空サイトのため外部業務システムや認証を偽装しない。全リンク・ボタンに意味のある動作を実装。写真は共通 assets/campus.jpg、classroom.jpg、library.jpg、basketball.jpg、students.jpg を利用し、必要に応じCSSのobject-positionで使い分ける。写真準備は共通準備時間に含む。

## Adaptation from reference
参照コピーではなく、情報探索と学校への期待を両立する共通設計から独立制作する。学校紹介の細部文章は各モデルが作成してよい。計画書は本書1つに限定し、各studyのDESIGN.mdには本書へのリンクと実装上の判断のみを記録する。

## 並行制作と計測
A担当はこの会話のモデル、B担当は gpt-5.6-luna、推論極高=xhigh、Fast=priorityを要求する。Aはschool-astra/、Bはschool-luna/のみを書き、他案のソースを参照しない。共通素材と計画書は親担当が準備する。CLIを用いる場合は要求設定、実際に確認できたモデル設定、開始終了UTC、JSONLのusageを別々に保存。設定の受理と実際の配信tierを混同しない。取得できない数値は未取得とし推定で埋めない。

準備・制作・検証・全体の時刻を分ける。親担当には共通準備・統合の負荷があるため、全体使用量を純粋なモデル性能差と解釈しない。親の使用量はセッションログが取得できる場合に計測時点を添えて記録し、最終返信後の厳密な総量ではないことを明記する。
