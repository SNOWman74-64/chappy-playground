# Once Upon a Cup — Test report

実施日: 2026-09-07（Asia/Tokyo）

## Scope and evidence

ユーザー提供の `docs/model/once-upon-a-cup-computer-use.blend` をWeb用に最適化し、そのモデルを表示する静的サイトを追加した。変更対象は `once-upon-a-cup/`。本レポートは初回のローカル実装・検証の記録であり、その時点では元モデルの保存、コミット、プッシュ、デプロイ、外部ギャラリーへの登録は行っていない。その後の公開先はREADMEを参照。

モデルの記録は [optimization-report.json](evidence/optimization-report.json)、資産の整合性は [asset-verification.json](evidence/asset-verification.json) を参照。ブラウザ検証はこのタスク内の実ブラウザ操作、画面の目視、DOMの読み取り、診断値、コンソールによる。以下の画面確認はツール上で実施しており、検証スクリーンショット一式をファイルとして保存したという意味ではない。

## Model optimization

比較元は、スタジオの床・カメラ・照明を除いた同じカフェを未圧縮GLBに書き出したもの。圧縮済みの元 `.blend` とGLBの容量を直接比較していない。

| 項目 | 比較用GLB | Web用GLB | 削減率 |
| --- | ---: | ---: | ---: |
| ファイル容量 | 5,858,336 bytes | 383,840 bytes | 93.45% |
| 三角形 | 223,880 | 90,305 | 59.66% |
| メッシュ／プリミティブ | 972 | 14 | 98.56% |
| マテリアル | 14 | 14 | 0% |

文字の輪郭を保って厚みを省き、曲線・ベベルの分割を削減し、材質ごとに静止形状を統合した。最終GLBはDraco圧縮を使用する。元の本、屋根、ひさし、テラスの椅子とカップ、木、焼き菓子のワゴン、文字が保たれていることを画像と3D表示で確認した。

元モデルのSHA-256は処理前後で一致:

```text
5265706736f012cdd4d9cc67d5bb0124ae617592d3b0c54a766da2f6859bb866
```

最終 `assets/cafe.glb` のSHA-256:

```text
f9fafe5070c4e4f9dcc5e963bddac20cf70bfdb8497d1cbdc901eb7e955be2f7
```

整合性チェックはPASS。初期表示のWebPは96,822 bytes。同梱ランタイムはライセンス等を含め11ファイル・1,193,138 bytesで、マニフェストのハッシュと一致した。HTMLから参照するローカル資産が存在し、重複IDはなく、不要になったPNGは削除済み。モデル容量383,840 bytesはサイト全体や3D開始時の総転送量ではない。

| キーボード | 矢印、＋／−、Home、Escape、Tabによる移動 | PASS。回転・拡縮・復帰・終了が機能 |

320px幅の途中確認では、画像を112%に拡大する指定によりページ幅が332pxになっていた。900px以下で画像をステージの100%以内に収めるよう修正し、320px幅で横はみ出しがなくなったことを確認した。フォーカス枠はクリッピングに隠れないようボタン内側に表示している。

正常表示の診断値はモデル14メッシュ・90,305三角形。描画時は地面の2三角形を含め15描画呼び出し・90,307三角形だった。ローカルでの単発観測では初回読み込み54ms、CPU側の描画呼び出し0.5ms（1365 × 900）、読み込み61ms、CPU側1.3ms（390 × 844）。これらはキャッシュや検証環境に依存する単発値であり、ネットワーク性能、GPU時間、FPS、実機スマホ性能のベンチマークではない。

## Failure and recovery verification

検証専用サーバー `tools/serve_qa.py` の4174番ポートを使用。障害や設定の注入は検証用レスポンスだけに適用し、サイト本体やOS設定は変更していない。

| 条件 | 実施した操作・観測 | 結果 |
| --- | --- | --- |
| `/fail-once/` | 最初のGLB取得をHTTP 503で失敗させ、再試行 | PASS。初期画像と物語を維持し、再読み込みなしで3Dに復帰 |
| `/no-webgl/` | WebGLコンテキスト取得を失敗させる | PASS。画像・物語・再試行操作を残す。注入した失敗に由来するThree.jsのコンソールエラーは想定内 |
| `/reduced-motion/` | 検証ページで動きを減らす設定を注入し、テラスへ移動 | PASS。補間なしで倍率2.4の視点に移動し、その後フレーム数は増加しない |
| `/context-loss/` | 3D表示後に `WEBGL_lose_context` で描画を中断し、再試行 | PASS。復旧案内と初期画像に戻り、再読み込みなしで14メッシュ・90,305三角形の3Dに復帰 |

描画中断時は「3Dの描画が中断されました。もう一度ひらくことができます。」と表示し、キャンバスを取り除いて画像を復元した。再試行後は15描画呼び出し・90,307描画三角形で正常表示した。正常表示時の診断エラーは空だった。

## Static checks

最終チェックコマンド:

```powershell
node --check once-upon-a-cup/app.js
node --check once-upon-a-cup/viewer.js
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/check-ui-study.ps1 -Study once-upon-a-cup
```

結果: 3コマンドすべて終了コード0。`app.js` と `viewer.js` の構文チェックに成功し、`UI_STUDY_CHECK_PASS: once-upon-a-cup` を確認した。静的チェックだけを画面品質の根拠にはせず、上記の実ブラウザ検証と組み合わせている。

検証用サーバー（4174番ポート）はこのタスクのプロセスを終了した。通常プレビュー（4173番ポート）は継続して利用する。

## Limitations

実機iPhone／Androidでのタッチ・ピンチ、Safari、スマホGPU性能、長時間の発熱・電池消費は未確認。ブラウザ幅の変更を実機試験と同一視しない。動きを減らす設定は検証用注入による確認であり、実OS設定の切り替え試験ではない。

JavaScript無効時の `noscript` と画像による代替表示はソースで確認したが、実際にJavaScriptを無効化したブラウザでの試験は未実施。テストはモデルの外観を眺める体験を対象とし、店内の自由歩行は実装対象にしていない。

終了時に通常ページのコンソールを追加取得しようとしたが、ツール側の安全性チェックでブロックされた。上記のコンソールと画面の結果はそれ以前に成功した実ブラウザ検証によるもので、今回の再取得が成功したという意味ではない。最後のタブ一覧では通常プレビューだけが残っていることを確認した。一時ビューポート指定の解除は終了時点で再確認していない。
