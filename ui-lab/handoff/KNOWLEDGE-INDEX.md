# Knowledge Index

AI が UI Lab の durable knowledge を最小読込で取得するための router。

| Need | Read first | Then confirm in |
| --- | --- | --- |
| Harness / engineering decision | `DECISION-LOG.md` | relevant source / check / runtime |
| Shared UI rule | `../DESIGN.md` | current study / browser evidence |
| Cross-study design learning | `../knowledge/PATTERN-INDEX.md` | linked `../LEARNINGS.md` entry |
| Avoid / failure pattern | `../knowledge/ANTI-PATTERN-INDEX.md` | linked `../LEARNINGS.md` or preference source |
| Specific reference site | `../knowledge/sites/INDEX.md` | selected site profile + study evidence |
| Find a new reference | `../knowledge/REFERENCE-INDEX.md` | actual external reference |
| Observe / decompose a reference | `../knowledge/OBSERVATION-GUIDE.md` | actual reference + study `DESIGN.md` |
| Current taste hypothesis | `../knowledge/PREFERENCES.md` | repeated study evidence before promotion |
| Design Language / promotion model | `../knowledge/DESIGN-LANGUAGE.md` | canonical `../DESIGN.md` / `../LEARNINGS.md` |

Indexes route retrieval; they are not evidence or normative requirements by themselves.
