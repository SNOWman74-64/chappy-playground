# 共通受入れ基準

未実装のため全項目は未実施。実装担当の自己申告と独立評価を別欄に記録する。以下の項目を全案に等しく適用する。未検証はPASSにしない。

| ID | 操作・観測 | 合格条件 |
| --- | --- | --- |
| ENV | 実装担当自身がenvironment.htmlを開き画像/確認ボタン/Tabを操作 | 実ブラウザ接続とスクリーンショット取得に成功してから計測開始 |
| V01 | トップ/図鑑/記事/スレッド/編成を1440と390で表示 | 本文の横はみ出し・画像欠落・操作の重なりなし。表だけの局所スクロールは可 |
| V02 | 第一画面を同じ寸法で並べて評価 | 見出し・説明・操作の判別、情報階層、画像の役割、文字組みを各1〜5で採点し理由を書く。合計だけで判断しない |
| D01 | 図鑑で火＋支援を選択 | c05の1件。名前「存在しない」で0件、リセットで12件 |
| D02 | キャラの並べ替えと詳細URLを開く | 固定値に沿う順序、詳細と一覧でデータ一致、戻る/進むが成立 |
| S01 | 検索「結晶」「存在しない」を実行 | 前者は共通データの該当情報と遷移先、後者は0件。結果数が表示と一致 |
| A01 | 記事g01を保存/解除/再保存して再読込 | 保存一覧に正しく反映、記事本文と関連導線が存在 |
| T01 | c01,c02,c03,c04を編成、c01重複とc05追加を試す | 重複/満員で追加不可。1枠削除後に追加可能 |
| T02 | 編成共有URLを新しいタブで直接表示 | 同じ4枠が復元。不正ID・重複IDは説明して安全に処理 |
| B01 | スレッドカテゴリ「質問」で絞込み | t01,t03の2件。返信数順は固定データの件数と一致 |
| B02 | 新規投稿で空白/上限超過、正常入力→確認→修正→投稿 | 無効入力拒否、編集で値保持、正常投稿だけ1件増加 |
| B03 | 自分の返信を追加・編集・削除取消・削除確定 | 本文/件数が正しく変化し、再読込でも一致。他人の編集操作なし |
| B04 | 本文に <img src=x onerror=alert(1)> を入力 | 文字として表示され、実行されない |
| B05 | 他人の投稿の通報を操作 | 実送信なしで理由選択とデモ完了。通報だけで元投稿を消さない |
| P01 | 保存データを初期化し取消/確定 | 取消で維持、確定で初期シードへ戻る。他サイトのキーは残る |
| P02 | 保存先への書込み失敗/破損データで起動 | 白画面にせず一時利用/復旧案内。エラーを隠して保存成功と表示しない |
| K01 | Tab/Enterで主要導線、フォーム、開閉部品を操作 | 見えるフォーカス、ラベル、閉じる/Escape、遷移後メニュー閉鎖 |
| R01 | 必須詳細の直接URLと不明IDを開く | 正しい詳細/見つからない案内。pageerrorなし、必要資源のHTTP失敗なし |

固定データの全件を使う。試験用の文字を特別扱いする実装は禁止。機能の抜けは視覚得点で相殺しない。独立評価で見つけた不具合は、共通条件に従って修正へ戻すか初回成績として記録する。
