# Design
## Reference
[共通設計計画書](../school-comparison/DESIGN-PLAN.md)を唯一の設計計画とする。写真出典は共通ASSETS.md。
## Intent
学校の空気と実務情報を両立し、見学への導線を短くする。
## Visual DNA
写真と明朝の大きな日本語。緑の縦帯で学校の個性を示し、罫線で情報を整理する。
## Tokens
共通計画の色と16px本文を採用。幅1200px、余白24/48/96px。
## Layout Anatomy
二段ヘッダー、左右非対称の写真ヒーロー、横長の説明会帯、ニュース一覧と学校紹介を交互に置く。下層は共通のパンくず・見出し・本文幅。
## Interaction / Motion
ハッシュルーティング。検索・絞り込み・詳細・フォームの確認と完了。動きはhoverとメニュー状態のみ。
## Constraints
静的デモ。個人情報を保存・送信しない。資料は印刷用HTML。
## Adaptation from reference
共通条件内で、誌面のような余白と情報の一覧性を優先。
