# daybook — Retrospective

## What worked

- Reference の design system を読むだけでも、専用 UI Agent なしでかなり近い visual language を作れた
- orange の「色」ではなく「annotation role」を維持したことで、別ブランドでも空気が残った
- HTML / CSS だけの stationery object でも tactile な印象を作れた
- extreme type scale が全体の identity を強くした

## What felt wrong

- Web UI へ整える過程で、一部に card / contained section の文法が残った
- 「参考元の紙・文具感」と「AI が作りがちな整ったカード」の両方が同居した
- 情報を整頓するほど reference の loose な感じが弱くなった

## Fixes / next experiment

- card を禁止して同じ design DNA を再構成する
- information group を whitespace / rule / margin / handwritten annotation で作る
- UI を紙の上に載せるのではなく、紙そのものを layout にする

## Open questions

- cardless にすると可読性や操作性はどこまで維持できるか
- mobile でも tactile な表現を自然に保てるか
- intentional imperfection をどこまで強くしても雑に見えないか

## Candidates for shared learnings

- Card is not the default grouping tool
- Preserve color roles, not only values
- Extract design grammar before copying layout
